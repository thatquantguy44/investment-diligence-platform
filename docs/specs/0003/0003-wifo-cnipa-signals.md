# Spec 0003: WIFO and CNIPA Signals

**Status:** Placeholder for discussion

**Last updated:** 2026-10-11

## Purpose

Reserve a lightweight future spec for possible signals from WIFO-related public
economic data and CNIPA-related intellectual-property records.

This is only a placeholder. The source boundaries, use cases, access terms,
geography, language, fields, and implementation sequence have not been decided.

## Candidate sources

- WIFO — candidate public economic or research datasets; exact source and use
  case to be selected.
- CNIPA — candidate public intellectual-property records; exact endpoint,
  dataset, language, and permitted collection method to be selected.

## Explicit non-commitments

- No connector, credential, source manifest, schedule, or live collection is
  approved by this placeholder.
- No claim is made that either source is currently integrated into the
  repository.
- Any future build must preserve source provenance, original evidence, access
  terms, and uncertainty under the controls established by Spec 0001.
